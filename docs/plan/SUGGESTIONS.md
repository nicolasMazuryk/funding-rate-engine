- **[adapters/binance/getOrder symbol map]** — `getOrder(clientOrderId)` resolves its required venue symbol from an in-memory `clientOrderId→venueSymbol` map the private stream fills from `ORDER_TRADE_UPDATE`; an unknown id throws `NotFound` (no `fetchOpenOrders` scan).
